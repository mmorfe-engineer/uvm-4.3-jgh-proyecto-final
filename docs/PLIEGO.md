## 1. DESCRIPCIÓN DE LA ACTIVIDAD
Realizar una aplicación web con HTML, CSS y JavaScript.

Debe contener:
1. **Animaciones web.**
2. **Cambio dinámico de contenido** mediante JavaScript.
3. **Consumo de información desde una base de datos** a través de una API desarrollada en Node.js y Express.
4. **Programación asíncrona.**
5. **UX/UI con loaders y transiciones.**
6. **Formulario de contacto de cinco campos como mínimo**, de diferentes tipos:
   - `email`
   - `number`
   - `date`
   - `phone` / `radio button`
   - `file`
7. **Almacenamiento de los datos** suministrados por el usuario.
8. **Validación de información ingresada**, evitando campos vacíos y elementos no permitidos.
9. **Buscador que filtre los datos** mostrados por la aplicación.

La página web debe encontrarse en un estado **100 % funcional**.
